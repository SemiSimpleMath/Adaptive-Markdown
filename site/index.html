Markdown that runs.

Plain .md files a coding agent can rewrite, restyle, illustrate, animate, or extend in place — including arbitrary HTML, CSS, and JavaScript that ships inside the doc. The page you see is the file, executing.

What this is

An open format. Plain CommonMark markdown plus a small set of conventions — pandoc-style heading attributes, ::: directives for figures and asides, embedded <style> / <script> blocks. Renders cleanly in any markdown viewer; the format invariant is "the file works everywhere."

An agent skill. A ~350-line text file (SKILL.md) that teaches a coding agent how to operate on this format predictably — preserve tracking IDs, write KaTeX-safe math, write self-contained figure programs, etc. The skill is the contract; the agent is replaceable. Today: Claude Agent SDK as the supported runtime; experimental Codex CLI adapter alongside.

A local viewer. A 2000-line single-file HTML/JS app that renders the doc in a sandboxed iframe, pipes click-to-focus selections over a WebSocket to the agent, and applies edits live. Math via KaTeX. History snapshots, derived per-block patches, the works.

Get it

Requires Python 3.10+ and an Anthropic API key (or an OpenAI / ChatGPT-account login for the experimental Codex runtime). Runs entirely on your machine.

git clone https://github.com/SemiSimpleMath/Adaptive-Markdown
cd Adaptive-Markdown
pip install -r requirements.txt
python start.py --claude       # or --codex (experimental)

Open http://127.0.0.1:8090. The tutorial doc loads by default.

Things to try

The tutorial doc walks through these — but the prompts work on any block in any doc.

Rewrite this for a 10-year-old.

Click an ε-δ continuity definition; the agent rewrites it in place. Source updates; render re-flows.

Translate this paragraph to French.

Click the focused block, give an instruction. The agent edits exactly that block, preserving tracking IDs and surrounding content.

Add a figure that animates the unit circle.

The agent writes a :::figure directive with an inline <canvas> and the JavaScript that draws it — into your markdown source.

Add a dark-mode toggle and put a small game in the corner.

Page-level effects work the same way: the agent appends <style> and <script> blocks to the markdown. The doc is its own webpage.

For the curious

The format spec covers file shape, the two-tier identity model (anchor IDs and tracking IDs), directive vocabulary, math conventions, and the sidecar files (.history/, .patches/, alias maps). The skill text is the agent's normative contract — read it if you want to write an alternative agent. The roadmap covers what's coming (component / resource libraries, Pyodide for in-browser Python, Lean verification, multi-document workspace).

It's v0.1. Things work; rough edges exist. Issues and PRs welcome.
